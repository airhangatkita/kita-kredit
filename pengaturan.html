Backup & Restore Data

Simpan atau pulihkan data KITA KREDIT

Backup Data

Download seluruh data KITA KREDIT dalam format JSON. Backup dapat digunakan sebagai salinan data sebelum melakukan perubahan besar.

Restore Data

Pulihkan data dari file backup JSON KITA KREDIT. Data yang sedang digunakan akan diganti dengan data dari file backup.

Penting: Backup hanya menyimpan data aplikasi dari Local Storage. Informasi login/session tidak ikut disimpan. Sebelum restore, sistem akan membuat backup otomatis dari data yang sedang digunakan.
Disarankan melakukan backup secara berkala, terutama sebelum menghapus pelanggan, mengubah transaksi, atau melakukan pengujian fitur baru.
